# 个人工作台

一款**单文件、离线、零依赖**的个人效率工具：待办、快捷链接、专注番茄钟、知识库笔记。
把整个应用装进一个 `index.html`,数据永远在你自己的电脑里。

> 免费开源。如果你觉得「把生活装进一个本地文件」很对味,文末有作者的进阶作品。

## 特性

- **单文件**:CSS/JS 全部内联,拷到哪用到哪,U 盘也能跑
- **离线**:不联网、不上传,数据只存在你的浏览器与本地磁盘
- **待办**:优先级、截止日、重复任务、子任务
- **链接**:常用网站与本地文件夹一页直达(文件夹从浏览器原生打开)
- **专注**:番茄钟,记录专注轨迹
- **知识库**:搜索与阅读你的 Markdown 笔记文件夹(双链语法支持)
- **数据自动落盘**:授权一次数据目录,之后每次改动静默写盘
- **跨浏览器数据跟随**:换浏览器打开自动读回同目录数据文件,不"看起来丢了"
- **兼容性**:Edge / Chrome / 360 等主流 Chromium 内核浏览器全功能可用
- **深浅色主题**、快捷键全键盘操作

## 快速开始

**方式一(零安装)**:下载 `index.html`,双击,完事。

**方式二(一键安装)**:本仓库只提供 `index.html` 本体。如需一键安装包(创建桌面/开始菜单快捷方式),请自行生成或联系作者获取。

首次打开自带几条示例数据,直接编辑或删除即可。

### 快捷键

| 按键 | 功能 |
|---|---|
| `Ctrl+Shift+K` | 快速跳转任意页面 |
| `Ctrl+Shift+W` / `/` | 搜索当前页 |
| `1`–`5` | 切换前五个页面 |

| `T` | 深色 / 浅色 |

## 数据与隐私

- 数据保存在浏览器本地 + 你授权的数据目录,**不上传任何服务器**。
- **跨浏览器**:数据目录里除 `工作台数据.json` 外,会同步镜像一份 `工作台数据.js`(供无目录授权的浏览器经 `<script src>` 读回,不受 file:// CORS 限制)。两份内容一致,都可放心备份/删除;删掉后下次保存会重建。
- 迁移:设置里「导出」成 JSON,新机器「导入」即可。
- 知识库模块:把你的 Markdown 笔记文件夹命名为 `我的知识库`,与 index.html 放同一目录即可被搜索;路径变更可在控制台 `store.set('ws_kbpath','新路径')`。

### 浏览器兼容性说明

| 浏览器 | 全部功能 | 自动落盘 | 跨浏览器自动恢复 |
|---|---|---|---|
| Edge / Chrome(新版) | ✅ | ✅ 授权一次后静默写盘 | ✅ 主动写镜像 |
| 360 浏览器(Chromium 内核) | ✅ | ✅ | ✅ 读镜像恢复 |
| Firefox / Safari | ✅ 界面与全部本地功能 | ⚠️ 浏览器不提供该 API,用「导出/导入」备份 | ⚠️ 手动导入 |

